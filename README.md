# The Ledger — Claims Audit

This repository is the canonical claims audit for The Ledger (https://ledgerandregister.substack.com). Each paper's `claims.csv` tracks every quantitative claim: the claim, its source, its status.

**Statuses:** SOURCED (primary or official reproduction attached) · PENDING (asserted, not yet closed) · DISPUTED (credible sources conflict; both cited) · LIVE (event-register row, still moving). Negative findings remain in the table.

The commit history is the permanent record of every change. The `notes` column preserves each row's full status detail, including corrections and their history.

**To challenge a row:** open an issue naming the `row_id` and what would satisfy you — see The Referee's Invitation on the publication. Corrections publish with credit.
